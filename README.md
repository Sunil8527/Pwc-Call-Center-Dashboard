# Call Centre Data Analysis (Power BI)

## 📊 Overview
This project analyzes call centre performance using Power BI dashboards.  
It provides insights into customer satisfaction, agent efficiency, and call trends over time.

## 🔑 Key Metrics
- Total Calls: 5000  
- Customer Satisfaction: 68.07%  
- Calls Resolved: 89.94%  
- Calls Abandoned: 18.92%  
- Average Speed of Answer: 67.52 seconds  
- Average Talk Time: 224.92 seconds  

## 👩‍💼 Agent Performance
- Resolution rate across agents: ~88–91%  
- Highest customer satisfaction: Joe (69.42%)  
- Consistent performers: Becky & Diane (89.06% resolution)  

## ⭐ Customer Ratings
- Average: 1218 calls  
- Good: 1180 calls  
- Excellent: 843 calls  
- Negative (Bad + Very Bad): 813 calls  

## 📈 Call Trends
- **Hourly:** Steady volume between 09:00–18:00 (~550–566 calls/hour)  
- **Daily:** Peak on Monday (770 calls) and Saturday (768 calls)  

## 🎯 Insights
- Strong resolution rate (~90%) but customer satisfaction (~68%) needs improvement.  
- Joe and Dan’s practices can be replicated across the team.  
- Monday and Saturday are peak days → require better staffing/scheduling.  
- Focus on improving service quality to increase “Excellent” ratings.
